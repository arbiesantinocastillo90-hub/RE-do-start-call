# GitHub repository and collaboration

The official repository exists at **https://github.com/arbiesantinocastillo90-hub/RE-do-start-call**.

Its GitHub slug `RE-do-start-call` represents the game title **RE:(do)(start)(call)**. The repository was initialized in the user's account and the project source was subsequently published from the development workspace.

## Clone and run

```sh
git clone https://github.com/arbiesantinocastillo90-hub/RE-do-start-call.git
cd RE-do-start-call
node tests/engine.test.js
node tests/autoplay.test.js
```

Open `web/index.html` to play the browser version. For the native build, import `project.godot` in Godot 4.x and run the default scene. The native Godot editor/runtime remains to be independently validated on a machine with Godot installed.

## Collaboration

Follow `AGENTS.md` and `docs/GPT_INTERFACES.md`. Open a GitHub issue for changes and create a topic branch. Assign files to one owner, submit a pull request to `main`, and run the included Node.js tests before merging. The GitHub Actions workflow in `.github/workflows/tests.yml` provides automated JavaScript logic checks.

Do not commit credential files, unlicensed third-party assets, or identifiable sensitive information. The story should depict childhood trauma symbolically and maintain the prospect of receiving help rather than sensationalizing abuse.
